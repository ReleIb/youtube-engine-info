Privacy Policy

Last updated: 23 October 2026

This policy covers UBT Stories / YouTube Engine, a local video production and publishing application operated by Refik Ibrahimović (ReleIb), and this public information website. It applies to each YouTube channel connected to the application with the channel owner's authorization.

1. Information the application accesses

The application uses YouTube API Services. Depending on the Google permissions granted and features used, it accesses:

  • Channel identifiers, channel names and information needed to identify the authorized channel.
  • Video identifiers, titles, descriptions, thumbnails, publishing settings and other video metadata.
  • Channel and video performance reports, including revenue reports only when the relevant permission is granted.
  • OAuth access tokens, refresh tokens and their expiry information to maintain the authorized connection.
  • Video files, production inputs and publishing details provided or created by the operator.

The application does not ask for or store the Google Account password. Google handles sign-in and consent.

2. Why information is used

Information is used to connect the intended channel, prepare and publish the operator's content, display publishing status, and evaluate channel and video performance. Access is limited by the scopes granted through Google. Connecting another channel requires a separate authorization; existing authorization does not automatically grant access to every channel.

3. Storage and retention

The engine runs locally. Its configured local files and database hold connection records, tokens, channel settings and production records. Access tokens are renewed using the corresponding refresh token while authorization remains valid. The operator controls the computer, access to these records and any backups.

Tokens are kept while needed for an authorized connection. Stored YouTube API data must be refreshed or deleted in line with YouTube's applicable retention requirements. The operator can request removal of local connection and API data at any time using the contact below. Revoking Google access stops future authorized API calls but does not itself erase copies already stored locally or delete published YouTube videos.

4. Sharing and external services

Google and YouTube receive API requests and content submitted for upload. Production workflows can also use separately configured media and AI providers, such as ElevenLabs for narration, which process the text or media submitted to them. Where the operator submits channel or analytics information to an external analysis service, that service receives the submitted information for the requested analysis. The operator is responsible for enabling only necessary transfers and reviewing each provider's data practices.

Google authorization tokens are used for the Google connection and must not be included in media generation or analysis prompts. Google user data is not sold, used for advertising profiles, or used to train generalized AI models. Any transfer of information obtained through Google APIs is subject to the Google API Services User Data Policy, including its Limited Use requirements. Information may also be disclosed where legally required.

5. This public website

These static pages do not run the local engine, accept Google sign-ins or collect OAuth tokens. They have no application analytics scripts, advertising, forms or tracking cookies. GitHub Pages hosts them and may process technical request information, including visitor IP addresses, for service operation and security. See the GitHub Privacy Statement. Following external links opens services governed by their own policies.

6. Disconnecting and deleting data

Revoke access through Google Account connections, by selecting the application's entry. To request deletion of stored application data, contact refikrele@gmail.com and identify the affected channel. Do not send passwords, tokens or other secrets. The operator will remove the applicable tokens and stored API data from the application's active storage within seven days of a verified deletion request and arrange removal from operator-controlled backups. Videos already uploaded to YouTube must be managed separately through YouTube.

7. Google and YouTube privacy

Google's processing is described in the Google Privacy Policy. Use of the YouTube integration is also subject to the YouTube Terms of Service.

8. Contact and changes

Operator: Refik Ibrahimović (ReleIb). Contact: refikrele@gmail.com. Privacy questions, access requests, correction requests and deletion requests can be sent to this address. This policy will be updated when application data practices change; the revision date appears above.
